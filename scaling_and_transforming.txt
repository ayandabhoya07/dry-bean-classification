# 📝 DATA PREPROCESSING, DIAGNOSTICS, AND SCALING NOTES

## 1. DIAGNOSTIC PLOTS (UNDERSTANDING THE SHAPE)
When assessing features using the code: fig, axes = plt.subplots(1, 2, figsize=(14, 5))

* Histogram & KDE (Left Plot):
  - Shows the actual distribution shape, symmetry, and data frequency peaks.
  - Left-Skewed: The data tail stretches long toward the left (e.g., the Extent feature).
  - Multi-modal: Displays multiple distinct peaks. On the Dry Bean Dataset, this indicates underlying sub-populations (the 7 different bean classes).
* Q-Q Plot / Quantile-Quantile (Right Plot):
  - Compares the distribution of your dataset against a standard normal distribution (the diagonal red line).
  - Normality: The blue dots sit directly on top of the red line.
  - S-Shape / Wave Pattern: Indicates severe deviation from normality. It means the data tails are lighter or heavier than what a normal distribution expects.

## 2. DATA TRANSFORMERS (CHANGING SHAPE)
* Core Concept: 
  - Transformers alter the actual mathematical shape of your distribution. They force skewed or multi-modal data into a symmetric, bell-shaped normal curve.
* When to use: 
  - Essential for Parametric Models and statistical tests (Linear Regression, Logistic Regression, ANOVA, t-tests, and PCA). These methods break down or yield flawed results if data is heavily skewed.
* When to skip: 
  - Skip for Tree-Based Models (Random Forest, XGBoost, LightGBM, CatBoost) because they split data using thresholds and care only about numerical order, not distribution shapes.
* Key Tools:
  - Reflected Log/Sqrt: Manually flips left-skewed data before applying a log or square root function.
  - Yeo-Johnson (PowerTransformer): An automated scikit-learn pipeline tool that automatically calculates the optimal mathematical parameter to stabilize variance and minimize skewness for both positive and negative numbers.

## 3. DATA SCALERS (CHANGING RANGE)
* Core Concept: 
  - Scalers preserve the exact shape, curves, and peaks of your data. They simply change the range of the numbers on the axes so features with massive scales (e.g., Area in the thousands) do not mathematically overpower small scales (e.g., Solidity or Extent decimals).

* StandardScaler:
  - Shifts data to have a mean of 0 and a standard deviation of 1.
  - Best Used For: Artificial Neural Networks (MLP), Logistic Regression, Support Vector Machines (SVM).
* MinMaxScaler:
  - Compresses all feature values strictly between a minimum of 0 and a maximum of 1.
  - Best Used For: K-Nearest Neighbors (KNN) and Distance-based clustering models.
* RobustScaler:
  - Scales features using the median and Interquartile Range (IQR).
  - Best Used For: Datasets with extreme, unremoved outliers that would otherwise distort the mean and variance.
* No Scaler Needed:
  - Leaves numbers completely in their raw, natural metric state.
  - Best Used For: Tree-based ensemble models (XGBoost, Random Forest, LightGBM, Decision Trees).

## 4. CODE CHEAT SHEET FOR MODEL PIPELINES

* Checking Normality Mathematically (Shapiro-Wilk Test):
  - If the p-value is greater than 0.05, the feature is statistically close to a normal distribution.
  ```python
  import scipy.stats as stats
  stat, p_value = stats.shapiro(df['Extent'].sample(500)) # Subsample if dataset > 5000 rows
  print(f"P-value: {p_value} -> {'Normal' if p_value > 0.05 else 'Not Normal'}")

  ```
#The Shapiro-Wilk test and the Kolmogorov-Smirnov test are statistical tools used to check if a set of data follows a specific theoretical distribution, most commonly a normal (bell-curve) distribution.

* Processing All Columns Dynamically (Scikit-Learn ColumnTransformer):
  - Scale or transform numerical features at the exact same time while protecting text target labels (like the 'Class' column).
  ```python
  from sklearn.compose import ColumnTransformer
  from sklearn.preprocessing import StandardScaler # Swap with PowerTransformer(method='yeo-johnson') if transforming

  numeric_features = [
      'Area', 'Perimeter', 'MajorAxisLength', 'MinorAxisLength', 
      'AspectRatio', 'Eccentricity', 'ConvexArea', 'EquivDiameter', 
      'Extent', 'Solidity', 'Roundness', 'Compactness'
  ]

  preprocessor = ColumnTransformer(
      transformers=[
          ('num_processing', StandardScaler(), numeric_features)
      ],
      remainder='passthrough' # Keeps the target 'Class' column untouched
  )
  ```
